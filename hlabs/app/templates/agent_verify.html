HackUMass Labs welcomes well-behaved automated clients, including AI assistants acting for our customers. To keep the platform fast for everyone, automated clients are asked to verify each session once and to follow the guidelines below.

Guidelines for automated clients

  • Identify yourself with a descriptive User-Agent that includes a contact address.
  • Keep to 1 request per second for HTML pages. The API allows 600 requests per minute per key.
  • Prefer the JSON API over scraping pages. See the API reference.
  • Customer and staff areas require the same credentials a person would use. Verification does not grant extra access.

Using the API

Most information on this site is available from the API with an account key:

curl https://hackumass-labs.example/api/v1/models \
  -H "Authorization: Bearer $HL_API_KEY"

Account keys are listed on the account dashboard. Staff tools are documented internally and are not covered here.

Questions

If your client was blocked or rate limited, or you run an integration on behalf of a customer, write to us through the contact form and include your verification key.
