API reference

REST API, JSON responses. Base path /api/v1.

Authentication

Create a token on your account page and send it as Authorization: Bearer <token>. Tokens start with hl_live_.

Endpoints

GET /api/v1/modelsList models you can access (public, plus your private models with a token).
GET /api/v1/meThe account that owns the token.
GET /api/v1/users/{id}Your user record.
GET /api/v1/invoicesYour invoices.
GET /api/v1/invoices/{id}One invoice.

Example

curl -H "Authorization: Bearer hl_live_..." https://hackumass-labs.example/api/v1/models
